    After you log in, many sites give your browser a JWT (JSON Web Token). The browser sends it back with every click to say who you are. The server signs it with its private key. Anyone can read it and change it. Only a check with the server's public key shows whether it was changed.

    How the server checks the signature

      When the server made the token, it hashed the same header.payload text and signed that fingerprint with its private key. To check, it hashes what arrived and asks: does this signature fit this fingerprint and my public key?
